# ساخت اپ اندروید یدک‌پرایس (پروژه Android Studio)

## ⚡ سریع‌ترین راه برای گرفتن APK واقعی: بدون نصب هیچ‌چیزی روی رایانه‌ات
اگر فقط می‌خواهی APK را دانلود و نصب کنی (نه توسعه کد)، به‌جای مراحل زیر مستقیم برو سراغ `GET_APK_NOW_FA.md` — با GitHub Actions (رایگان)، در چند دقیقه APK واقعی و کامپایل‌شده می‌گیری، فقط با مرورگر، بدون نصب Android Studio.

## صادقانه و شفاف: این پوشه چیست و چه چیزی نیست
این یک **پروژه کامل و واقعی Android Studio (Gradle)** است — کد Java، تنظیمات Gradle، مانیفست، آیکون و تمام فایل‌های وب برنامه (`assets/www/`، شامل کاتالوگ واقعی ۲۰۱۰ کالایی) از قبل داخل آن قرار گرفته‌اند. **اما** محیطی که این پروژه در آن ساخته شده نه به اینترنت دسترسی دارد و نه Android SDK/Gradle نصب‌شده‌ای — پس **فایل APK را اینجا کامپایل نکردم** چون نمی‌توانستم آن را واقعاً بسازم و تست کنم؛ ادعای داشتن یک APK کارکرده بدون این‌که واقعاً ساخته و آزمایش شود، به‌جای کمک، گمراه‌کننده است.

آنچه تحویل داده شده: **سورسی که با یک کلیک در Android Studio به APK واقعی تبدیل می‌شود**، نه یک APK ساخته‌شده.

## چرا WebView ساده کافی نبود
به‌جای بارگذاری ساده فایل‌ها با `file://` (که در خیلی از نمونه‌های آنلاین دیده می‌شود)، از `androidx.webkit.WebViewAssetLoader` استفاده شده تا برنامه از یک دامنه مجازی `https://appassets.androidplatform.net/` سرو شود. دلیل فنی: مرورگرهای مبتنی بر Chromium (از جمله WebView اندروید) اجازه نمی‌دهند `fetch()` یا IndexedDB به‌طور کامل روی `file://` کار کنند — دقیقاً همان‌هایی که `app.js` برای بارگذاری کاتالوگ اولیه (`seed-data.json`) و ذخیره‌سازی کالاها به آن‌ها نیاز دارد. بدون این تغییر، اپ باز می‌شد ولی کاتالوگ خالی می‌ماند.

## مراحل ساخت APK (روی رایانه خودتان، با اینترنت)
1. [Android Studio](https://developer.android.com/studio) را نصب کنید (رایگان؛ Gradle و Android SDK را خودش مدیریت می‌کند).
2. Open → همین پوشه `android/` را انتخاب کنید.
3. صبر کنید تا Gradle Sync تمام شود (بار اول به اینترنت نیاز دارد تا وابستگی‌ها را دانلود کند).
4. از منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. فایل خروجی در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود؛ آن را به گوشی منتقل و نصب کنید (ممکن است لازم باشد «نصب از منابع ناشناس» را در تنظیمات اندروید فعال کنید).
برای نسخه قابل انتشار (امضاشده) از **Build → Generate Signed Bundle / APK** استفاده کنید؛ به یک کلید امضا نیاز دارید که Android Studio در همان مسیر کمک می‌سازد.

### جایگزین بدون Android Studio
اگر Gradle به‌صورت جداگانه نصب دارید:
```bash
cd android
gradle wrapper          # یک‌بار، برای ساخت gradlew (این پوشه فایل‌های wrapper را همراه ندارد چون دانلود باینری gradle-wrapper.jar به اینترنت نیاز داشت و در این محیط ممکن نبود)
./gradlew assembleDebug
```

## وضعیت واقعی تأیید در این محیط
- ✅ کامپایل‌پذیری کد جاوا و XML با چشم و با دانش Gradle/Android API بررسی شد (ساختار استاندارد، نسخه‌های API معقول minSdk 24 / target 34).
- ❌ `gradle sync`، کامپایل واقعی، نصب روی اموالاتور/گوشی — **هیچ‌کدام در این محیط اجرا نشد** (نبود SDK و اینترنت).
- اگر اولین Build خطا داد، محتمل‌ترین دلیل عدم تطابق نسخه Android Gradle Plugin (`8.5.2` در `build.gradle` ریشه) با نسخه Android Studio نصب‌شده شماست؛ Android Studio معمولاً خودش پیشنهاد به‌روزرسانی می‌دهد — همان پیشنهاد را بپذیرید.

## نکته درباره کاتالوگ
همان کاتالوگ واقعی ۲۰۱۰ کالایی (از `list_asli14050714.xlsx`) داخل `assets/www/seed-data.json` بسته‌بندی شده و در اولین اجرای اپ به‌صورت خودکار بارگذاری می‌شود — نیازی به وارد کردن دستی فایل نیست.

## اگر ترجیح می‌دهید همین امروز، بدون کامپایل، چیزی روی گوشی نصب کنید
نسخه PWA (پوشه `client/`، همان فایل‌های داخل `assets/www/` این پروژه) را می‌توانید بدون هیچ کامپایلی، فقط با میزبانی روی HTTPS و «افزودن به صفحه اصلی» در Chrome نصب کنید — دقیقاً مثل یک اپ، همین الان. راهنما: `../docs/INSTALL_ANDROID.md`.
