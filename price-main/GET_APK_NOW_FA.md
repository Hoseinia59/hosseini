# گرفتن فایل APK واقعی — همین الان، بدون نصب هیچ‌چیزی روی رایانه خودتان

## چرا خودم نمی‌توانم همین‌جا APK بسازم
محیطی که من در آن کار می‌کنم نه Android SDK دارد، نه Gradle، نه اتصال اینترنت. کامپایل اندروید بدون این سه، فنی‌ترین و بدون استثنا غیرممکن است — نه محدودیت دلخواه من. راهی که پایین آمده، واقعاً APK واقعی می‌سازد، چون کامپایل را به سرورهای **GitHub** (که این‌ها را از قبل دارند، رایگان) می‌سپارد.

## مراحل (حدود ۵ تا ۱۰ دقیقه، فقط با مرورگر)

### ۱. یک مخزن (repository) رایگان در GitHub بساز
- وارد github.com شو (اگر حساب نداری، ثبت‌نام رایگان است).
- دکمه سبز **New repository** → یک نام بده (مثلاً `yadak-price-android`) → **Public** یا **Private**، فرقی نمی‌کند → **Create repository**.

### ۲. محتویات همین پوشه `android/` را در آن مخزن آپلود کن
- در صفحه مخزن خالی، روی لینک **uploading an existing file** کلیک کن.
- از رایانه‌ات، **تمام فایل‌ها و پوشه‌های داخل `android/`** (یعنی `app/`، `.github/`، `build.gradle`، `settings.gradle`، `gradle.properties`، همین فایل‌ها — نه خود پوشه `android` به‌عنوان یک پوشه، بلکه محتویاتش) را بکش و رها کن.
  ⚠️ نکته مهم: محتویات باید مستقیماً در **ریشه مخزن** باشند، نه داخل یک پوشه به اسم android. یعنی بعد از آپلود باید در ریشه مخزن مستقیماً پوشه‌های `app` و `.github` و فایل `build.gradle` را ببینی.
- پایین صفحه، **Commit changes** را بزن.

### ۳. منتظر بمان تا GitHub خودش APK را بسازد
- به تب **Actions** در بالای صفحه مخزن برو.
- باید یک اجرای در حال انجام (یا تمام‌شده) با نام «ساخت APK یدک‌پرایس» ببینی؛ خودش با همان Commit قبلی شروع می‌شود (اگر شروع نشد، روی workflow کلیک کن و دکمه **Run workflow** را بزن).
- ساخت معمولاً ۲ تا ۵ دقیقه طول می‌کشد. رنگ سبز = موفق.

### ۴. فایل APK را دانلود کن
- روی همان اجرای سبزرنگ کلیک کن.
- پایین صفحه، بخش **Artifacts** را ببین؛ فایلی به اسم `yadak-price-debug-apk` آنجاست — دانلودش کن (یک فایل zip است که خودِ APK داخلش است).
- آن zip را باز کن، فایل `app-debug.apk` را به گوشی اندرویدت منتقل کن و نصبش کن (ممکن است لازم باشد «نصب از منابع ناشناس» را در تنظیمات گوشی موقتاً فعال کنی).

## اگر مرحله Build قرمز (خطا) شد
محتمل‌ترین دلیل: در مرحله ۲ محتویات را داخل یک پوشه با اسم `android` آپلود کرده‌ای به‌جای مستقیم در ریشه. فایل‌های مخزن را چک کن: `build.gradle` باید مستقیماً در ریشه باشد، نه در `android/build.gradle`. اگر اشتباه بود، فایل‌ها را در GitHub جابه‌جا کن (یا دوباره درست آپلود کن) و یک‌بار دیگر commit بزن — خودش دوباره build را اجرا می‌کند.
اگر باز هم خطا داد، روی همان اجرای قرمز کلیک کن، گزارش خطا (log) را باز کن، و متن خطا را برایم بفرست تا دقیقاً بگویم مشکل کجاست.

## این APK چیست دقیقاً؟
نسخه «debug» — یعنی مستقیم روی گوشی قابل نصب است، کاتالوگ واقعی ۲٬۰۱۰ کالایی شما از قبل داخلش است، اما برای انتشار در فروشگاه‌هایی مثل بازار/مایکت باید بعداً «امضا» شود (مرحله جداگانه، در `README_BUILD_FA.md` توضیح داده شده) — برای نصب و استفاده شخصی روی گوشی خودت، همین کافی است.
